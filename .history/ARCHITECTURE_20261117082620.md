# Kiến Trúc Thư Mục: Scalable Feature-First (Next.js App Router)

Tài liệu này quy định cấu trúc thư mục, trách nhiệm của từng tầng và quy tắc phụ thuộc (Dependency Rules) nhằm đảm bảo dự án dễ mở rộng, tách biệt rõ ràng giữa **Routing**, **Business Logic** và **Shared UI**, đồng thời kiểm soát chặt ranh giới **Server / Client** trong Next.js.

---

## 1. Cây Thư Mục Tổng Quan

```text
src/
├── app/                        # [ROUTING LAYER] Định tuyến, Layout, Loading & Error Boundaries
│   ├── (auth)/                 # Route Group: Nhóm trang xác thực (/login, /register)
│   ├── (dashboard)/            # Route Group: Nhóm trang quản trị có Sidebar/Header
│   ├── api/                    # Route Handlers (REST endpoints nội bộ, webhooks)
│   ├── error.tsx               # Error Boundary toàn cục
│   ├── forbidden.tsx           # Giao diện lỗi 403 (kích hoạt bởi hàm forbidden())
│   ├── layout.tsx              # Root Layout: Nhúng <html>, <body>, AppProvider & main.scss
│   ├── not-found.tsx           # Giao diện trang 404
│   ├── page.tsx                # Trang chủ (/)
│   └── unauthorized.tsx        # Giao diện lỗi 401 (kích hoạt bởi hàm unauthorized())
│
├── features/                   # [DOMAIN LAYER] Cô lập nghiệp vụ theo từng tính năng độc lập
│   └── <feature-name>/         # Ví dụ: auth, products, cart, orders...
│       ├── api/                # Data fetching (Server fetchers, Server Actions, Client hooks)
│       ├── components/         # UI Components đặc thù chỉ phục vụ cho feature này
│       ├── hooks/              # Custom hooks chứa logic cục bộ của feature
│       ├── stores/             # Client state cục bộ của feature (Zustand / Redux slice)
│       ├── types/              # TypeScript interfaces/types của domain
│       ├── utils/              # Hàm xử lý logic/format riêng của feature
│       └── index.ts            # Public API: Cổng xuất khẩu duy nhất ra bên ngoài
│
├── components/                 # [SHARED UI] Component tái sử dụng toàn ứng dụng (không chứa nghiệp vụ)
│   ├── layout/                 # Khung bố cục dùng chung (Header, Footer, Sidebar, Container)
│   └── ui/                     # Nguyên tử giao diện (Button, Input, Modal, Table, Skeleton)
│
├── providers/                  # [PROVIDERS] Bọc các Context Providers toàn cục ('use client')
│   └── app-provider.tsx
│
├── styles/                     # [STYLING] Kiến trúc SCSS 7-1 chuẩn hóa
│   ├── abstracts/              # Variables, mixins, functions (không sinh ra CSS trực tiếp)
│   ├── base/                   # Reset CSS, typography, animations
│   ├── components/             # Style cho các UI components dùng chung
│   ├── layout/                 # Style cho header, footer, grid, sidebar
│   ├── pages/                  # Style đặc thù theo từng trang
│   ├── themes/                 # Quản lý theme (light/dark mode)
│   ├── vendors/                # Ghi đè CSS của thư viện bên thứ 3
│   └── main.scss               # File tổng hợp duy nhất được import tại src/app/layout.tsx
│
├── lib/                        # [INFRASTRUCTURE] Cấu hình & khởi tạo thư viện bên thứ 3
│   ├── fetch-client.ts         # HTTP client chuẩn hóa baseURL, headers, token, error handling
│   └── query-client.ts         # Cấu hình TanStack QueryClient tương thích SSR
│
├── hooks/                      # [SHARED HOOKS] Custom hooks dùng chung cho >= 2 features
│   └── index.ts
│
├── config/                     # [CONFIGURATION] Hằng số hệ thống & kiểm duyệt biến môi trường
│   ├── env.ts                  # Validate process.env bằng Zod
│   └── routes.ts               # Định nghĩa tập trung toàn bộ đường dẫn URL của ứng dụng
│
├── types/                      # [GLOBAL TYPES] Kiểu dữ liệu dùng chung (Pagination, ApiResponse...)
│   └── index.ts
│
├── utils/                      # [SHARED UTILS] Pure functions chạy được ở cả Server lẫn Client
│   └── index.ts
│
└── proxy.ts                    # [NETWORK GUARD] Chặn & điều hướng request (thay thế middleware.ts ở Next.js 16)
