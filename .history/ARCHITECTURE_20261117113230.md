# Kiến Trúc Dự Án: Scalable Feature-First (Next.js App Router)

---

## 1. Triết Lý Thiết Kế Cốt Lõi

1. **Co-location (Gom cụm theo nghiệp vụ):** Code thay đổi cùng nhau thì phải nằm cạnh nhau. Thay vì chia dự án theo loại file kỹ thuật (`components/`, `hooks/`, `services/` khổng lồ), toàn bộ giao diện, logic, state và API của một tính năng được đóng gói gọn trong `src/features/<tên-tính-năng>/`.
2. **Tách biệt Routing và Business Logic:** Thư mục `src/app/` chỉ làm nhiệm vụ định tuyến URL và điều phối dữ liệu cấp trang; không chứa logic nghiệp vụ phức tạp.
3. **Kiểm soát chặt ranh giới Server / Client:** Tận dụng tối đa React Server Components (RSC) để giảm dung lượng JavaScript gửi xuống trình duyệt, đồng thời ngăn chặn rò rỉ code server (database, secret keys) sang client bundle.
4. **Phụ thuộc một chiều (Unidirectional Architecture):** Mọi luồng import đều đi theo một hướng duy nhất từ tầng dùng chung $\rightarrow$ tầng tính năng $\rightarrow$ tầng định tuyến.

---

## 2. Cây Thư Mục Tổng Quan

```text
src/
├── app/                        # [ROUTING LAYER] Định tuyến, Layout, Metadata, Loading & Error UI
│   ├── (auth)/                 # Route Group: Nhóm trang xác thực (/login, /register)
│   │   ├── login/
│   │   │   └── page.tsx
│   │   └── layout.tsx
│   ├── (dashboard)/            # Route Group: Nhóm trang quản trị có Sidebar/Header
│   │   ├── products/
│   │   │   ├── [id]/
│   │   │   │   └── page.tsx
│   │   │   ├── loading.tsx     # Streaming Skeleton tự động khi tải dữ liệu SSR
│   │   │   └── page.tsx
│   │   └── layout.tsx
│   ├── api/                    # Route Handlers (REST endpoints nội bộ, webhooks, callbacks)
│   │   └── health/
│   │       └── route.ts
│   ├── error.tsx               # Error Boundary toàn cục ('use client')
│   ├── forbidden.tsx           # Giao diện lỗi 403 (kích hoạt qua hàm forbidden())
│   ├── layout.tsx              # Root Layout: Nhúng <html>, <body>, AppProvider & main.scss
│   ├── not-found.tsx           # Giao diện trang 404
│   ├── page.tsx                # Trang chủ (/)
│   └── unauthorized.tsx        # Giao diện lỗi 401 (kích hoạt qua hàm unauthorized())
│
├── features/                   # [DOMAIN LAYER] Các module nghiệp vụ độc lập
│   └── <feature-name>/         # Ví dụ: auth, products, cart, orders...
│       ├── api/                # Giao tiếp dữ liệu (Server fetchers, Server Actions, Client hooks)
│       ├── components/         # UI Components đặc thù chỉ phục vụ cho feature này
│       ├── hooks/              # Custom hooks chứa logic tương tác cục bộ của feature
│       ├── stores/             # Client state cục bộ (Zustand store / Redux slice)
│       ├── types/              # TypeScript interfaces/types riêng của domain
│       ├── utils/              # Hàm xử lý/validate/format riêng của feature
│       └── index.ts            # Public API: Cổng xuất khẩu duy nhất ra bên ngoài
│
├── components/                 # [SHARED UI] Component tái sử dụng toàn cục (không chứa nghiệp vụ)
│   ├── layout/                 # Khung bố cục dùng chung (Header, Footer, Sidebar, Container)
│   └── ui/                     # Nguyên tử giao diện (Button, Input, Modal, Table, Skeleton)
│
├── providers/                  # [PROVIDERS] Tập trung các Context Providers toàn cục ('use client')
│   └── app-provider.tsx
│
├── styles/                     # [STYLING] Kiến trúc SCSS 7-1 chuẩn hóa
│   ├── abstracts/              # Variables, mixins, functions (không sinh ra CSS trực tiếp)
│   ├── base/                   # Reset CSS, typography, animations
│   ├── components/             # Style cho các UI components dùng chung
│   ├── layout/                 # Style cho header, footer, grid, sidebar
│   ├── pages/                  # Style đặc thù theo từng trang
│   ├── themes/                 # Quản lý theme (light/dark mode)
│   ├── vendors/                # Ghi đè CSS của thư viện bên thứ 3
│   └── main.scss               # File tổng hợp duy nhất được import tại src/app/layout.tsx
│
├── lib/                        # [INFRASTRUCTURE] Cấu hình & đóng gói thư viện bên thứ 3
│   ├── fetch-client.ts         # HTTP client chuẩn hóa baseURL, headers, token, xử lý lỗi
│   └── query-client.ts         # Khởi tạo TanStack QueryClient tương thích SSR
│
├── hooks/                      # [SHARED HOOKS] Custom hooks dùng chung cho từ 2 features trở lên
│   └── index.ts
│
├── config/                     # [CONFIGURATION] Hằng số hệ thống & kiểm duyệt biến môi trường
│   ├── env.ts                  # Validate process.env bằng Zod
│   └── routes.ts               # Định nghĩa tập trung toàn bộ đường dẫn URL
│
├── types/                      # [GLOBAL TYPES] Kiểu dữ liệu dùng chung (Pagination, ApiResponse...)
│   └── index.ts
│
├── utils/                      # [SHARED UTILS] Pure functions chạy được ở cả Server lẫn Client
│   └── index.ts
│
└── proxy.ts                    # [NETWORK GUARD] Chặn & điều hướng request (thay thế middleware.ts ở Next.js 16)
